# measure — 자 (짝 비교 · 관문)

규약은 `protocol-g1.json` 하나다. 이 파일의 sha256 이 모든 결과에 `protocol_sha256` 으로 붙는다. 고치려면 새 판 파일(`protocol-g2.json`)을 만든다. 설계 `../Docs/Design/2026-10-11-d자료층재구축설계.md` 2-3 · 6-2.

1. **돌리기 (미니PC)** : `run/seed3.sh <조건> -- <train_nli 인자> --deterministic` 를 `G1_SEEDS="1 2 3 4 5"` 로 → 판 `g1-<조건>-s1`~`s5`. 규약 씨앗은 5 이고 학습은 결정 모드다(45-라 : 같은 씨앗이 비트 단위로 재현됨 · 학습 약 +20% 느림). 판마다 `eval-dev-cal` · `eval-dev-cmp` · 곁 자 평가, `calibration.json`(dev-cal 로), `eval-side.txt` 가 생긴다. 쌍을 더해 견줄 땐 `--replay-n` 을 기준 판 값에 묶는다.
   - **평가만 다시** : 학습만 한 판(`G1_TRAIN_ONLY=1`)은 `G1_EVAL_ONLY=1 run/seed3.sh <조건> --` 로 `runs/<판>/ckpt-best` 를 그대로 잰다 (재실행 판은 `G1_SEEDS=1 G1_SUFFIX=r` 를 같이).
   - **기준선 자 상태** : `python -I measure/baseline.py --protocol … --set <dev-cmp-g1.jsonl> --runs B0=<판1>/eval-dev-cmp,… --rerun <판1r>/eval-dev-cmp --out b.json --md b.md` → 판별 지표 · 씨앗 짝 반폭(3%p 가리나) · 재실행 차 · 곁 자. 거부 규칙은 compare 와 같다.
2. **짝 비교** : `python -I measure/compare.py --protocol measure/protocol-g1.json --set <dev-cmp-g1.jsonl> --base B0=<판1>/eval-dev-cmp,<판2>/…,<판3>/… --new B1=… --by domain,lang --out c.json --md c.md` → 먹힘 · 같다 · 지킴 깨짐 · 보류.
3. **릴리스 관문** : `python -I measure/gates.py release --protocol … --set <blind-g1.jsonl> --pred <판>/eval-blind --calibration <판>/calibration.json --ref-pred <v1.0.0 pred> --p95-ms <값>`. `gates.py pair …` 는 compare 와 같다.
   - **사전 등록** : `measure/prereg.py` 도 4칸 모델의 자를 `--protocol`(기본 `measure/protocol-g1.json`)의 `release_gate` 에서 읽어 `criteria` · `release_gate` · `protocol_sha256` 으로 박제한다. 코드에 자 숫자를 두지 않는다. fold40 을 관문에 넣으려면 새 규약에 `fold_wrong_max` 를 넣는다(g1 에는 없음).
4. **거부(exit 2)** : 판의 `summary.json` 에 `set_sha256` · `protocol_sha256` 이 없거나 다를 때, calibration 이 잴 셋으로 골라졌을 때(`calib_set_sha256` · 옛 `fitted_on.sha256`). 옛 판은 `eval_nli.py --protocol` 로 다시 잰다.
5. **옛 고리 관문** : `python -I measure/gates.py legacy <diag.json>…` — dev 8 + 곁 3(옆 `eval-side.txt`).
6. 시험 : `python -m unittest discover -s tests -p "test_compare.py"` · `"test_measure_gates.py"`.
7. **실사용 측정 use1** : `use_eval.py` (설계 `../Docs/Design/2026-10-12-실사용측정설계.md` · 규약 `protocol-use1.json` · 줄인 판 11-1). mem 이 실제로 묻는 자리 ①~③ 과 수집 자리 ④ ⑤ 에서 v1.0.0 · v1.1.0 을 같은 쌍으로 견준다. 합격선 없는 보고만 낸다. 「가른다」는 차가 `tell_min_pp`(10%p) 이상이고 구간이 0 을 안 넘을 때만 쓴다.
   - 차례 : `doctor --repo <뿌리> --alias A` → (v1.0.0 이 없으면) `serve --model ~/.judgemodel/models/nli-studio-v2 --port <빈 포트>` → `sample --repo <뿌리> --alias A --models v100=…,v110=…` (라벨이 있으면 멈춘다 · `--force` 면 옛 `labels/` 를 날짜 꼬리로 돌려 두고 다시 뽑는다) → `labels make|merge|third|decide|kappa|todo --alias A` → `freeze --alias A` → `report --alias A` → `stop --port <포트>`.
   - 쌍 본문 · 기록은 `~/.judgemodel/measure/use1/<별명>/` 에만 쓴다(git 밖 · 임시 llm.toml 에 키 없음). 대리 서버 기록 `queries.jsonl` 은 덧붙이기만 하고, 얼린 쌍 열쇠는 `use1/EXCLUDE.sha256list` 에 · 얼린 때는 `frozen.json` 의 `frozen_at` 에 남는다.
   - 하위명령은 `use_sites/` 모듈마다 `register(subparsers)` 하나로 더한다.
   - 쌍 id 는 `u<자리>-<쌍 열쇠 앞 12자>` 다. 다시 뽑아도 같은 쌍은 같은 id 이고, `freeze` 는 라벨 줄의 쌍 열쇠(`labels make` 때 사본 `labels/pairs.jsonl`)를 cands 와 대조해 다르면 exit 2.
   - ④ ⑤ 판 : `draw --place 4|5 --alias A` → `labels … --place 4|5` → `freeze --place 4|5` → `report --place 4|5`. 파일은 `cands-N.jsonl` · `labels-N/` · `set-use1-N.jsonl` · `FROZEN-use1-A-N.sha256` · 물음 기록 `queries-draw-N.jsonl`(얼리면 그 쌍 열쇠도 EXCLUDE 로). 얼린 판은 다시 안 뽑고, 다시 뽑으면 옛 `cands-N` · `draw-N.json` 을 날짜 꼬리로 돌려 둔다. 규약에서 `enabled` 가 꺼진 자리는 exit 2. ⑤ 별명 기본은 `harness`.
   - `report` 는 `--place` 없이 돌리면 얼린 판 전부(①~③ · ④ · ⑤)를 `result.md` 하나에, `--place N` 이면 `result-N.md` 에 쓴다.
   - 대리 서버는 reply 모델이 죽으면 502 를 그대로 낸다 — 다른 모델 답으로 바꿔 내면 mem 이 어느 모델 판정으로 움직였는지 흐려지기 때문이다(`proxy.py` 주석). `stop` 은 `/health` 이름이 기록과 다르면 내리지 않는다(exit 2).
   - 시험 : `python -I -m unittest discover -s tests -p "test_use_*.py"` (가짜 서버 둘 · `tests/fake_mem.py` · draw 는 `test_use_draw.py`).
   - ④ `harvest-reports --repo <뿌리> --alias A [--days 14] [--transcripts <폴더>]` · `log-report --repo <뿌리> --alias A --file <보고>|--stdin` (`use_sites/reports.py`) : `~/.claude/projects/<접은 경로>/*/subagents/agent-*.jsonl` 의 마지막 `SubagentHandback` 보고(없으면 끝난 마지막 assistant 글)만 읽어, 「정한 것」·「결정」 표 줄 · `정함 :` 줄 · `mem add --type decision` summary 를 claim 으로, 같은 scope 의 `mem search --type decision` 위 3건을 evidence 로 짝 짓고 `use1/A/collect/report-pairs.jsonl` 에 덧붙인다(열쇠 겹침 없음). 보고에 적힌 mem id · 보고 날과 같은 날이나 뒤의 기억은 뺀다. scope 는 `--scope x` → 툴 폴더 이름 → `officina`, 동률이면 `collect/skipped.jsonl`. 비밀 꼴은 `refused`. 셈은 `collect/harvest-reports.json`. 그다음 `draw --place 4 --alias A`.
