## 0. 전제

### 0-1. 왜 이 판인가

- **K2 는 한국어 c 를 크게 올렸지만 d 를 c 로 쓸어 가 지킴 셋이 깨졌다.** ko c +.117 [+.089, +.149] 인데 d 재현 −.146(아래끝 −.180) · en b 아래끝 −.056 · b 아래끝 −.035 다(짝 비교 1절).
- **d 는 거의 다 c 로 갔다**(d 정답 506 중 c 예측 85 → 176). 무너진 곳은 공개 원천의 「같은 대상인데 근거에 없는 다른 사실」 꼴뿐이다 — klue-mrc d .40 → .12 · vitaminc d .49 → .22. 우리 글(archive · mem) d 와 위키 wiki-edit d 는 그대로다(d 진단 0 · 2-1).
- **까닭은 「d 닻 없음」이다.** 학습 층의 공개 원천 d 397쌍은 모두 「같은 근거 · 고친 주장」(겹침 .79)이다. 그 위에 겹침 낮은 c 1,300쌍(겹침 .01~.07)을 더하자 「공개 원천 글 + 주장 사실이 근거에 없음 + 겹침 낮음 → c」로 굳었다. 닻이 있는 archive d(학습 266 · 겹침 .12)는 안 밀렸다(d 진단 3-1 · mem `20261014-80aedf49`).
- **가중치는 해법이 아니다.** K2 에서 d 가중이 1.52 → 1.73 으로 올랐는데도 d 가 내렸다(d 진단 4절 H3).

## 2. 목표와 합격선

### 2-1. 짝 비교 기준 판 — K 인가 K2 인가

| | **안 A : base K (추천)** | 안 B : base K2 |
| --- | --- | --- |
| 무엇을 재나 | 「K2 가 통과했어야 할 관문」을 K3 가 통과하나 | K2 에서 d 를 얼마나 되찾았나 |
| 목표 자 | `c_recall@ko` +.03 · 아래끝 > 0 (protocol-g4 그대로) | `d_recall` 같은 새 목표 |
| 지킴 | protocol-g4 아홉 줄 그대로 | K2 대비 지킴 — K2 가 이미 깎은 en b · b 를 기준으로 삼는다 |
| 좋은 점 | 기준선 `baseline-g4` 를 그대로 쓴다(재평가 0). 지킴이 K 가 얻은 것(ko b · en b · d)을 그대로 지킨다. 통과하면 blind 에 보낼 만한 판임이 바로 선다 | d 회복을 바로 잰다. 관문이 쉽다 |
| 나쁜 점 | 관문이 빡빡하다(아래 표). d 를 K 수준까지 거의 다 되찾아야 한다 | 실패한 판(K2)을 기준으로 삼아, 깎인 en b · b 가 「지킴 통과」로 묻힌다. blind 를 약한 판에 쓸 위험 |

- **추천 A.** 짝 비교의 일은 「blind 를 열 만한 판인가」를 거르는 것이다. B 로 통과해도 K 대비 en b · d 가 깎여 있으면 blind 관문(ref v1.1.0 대비)에서 같은 자리가 걸린다.
- **K2 대비 차는 보고만** 한다 — `compare.py --base K2=… --new K3=…` 를 한 번 더 돌려 `d_recall` · `c_recall@ko` · 원천별 표를 결과 문서에 싣는다. 판정에는 안 쓴다.

**통과에 드는 평균 차 (어림)** — K2 짝 비교의 차 구간 반폭을 그대로 쓴 값이다.

| 자 | 기준 | K2 구간 반폭 | 통과에 드는 평균 차 | K2 실제 |
| --- | --- | --- | --- | --- |
| `d_recall` | 아래끝 ≥ −.03 | 약 .033 | **≥ 0 언저리** | −.146 |
| `b_recall@en` | 아래끝 ≥ −.03 | 약 .026 | ≥ −.004 | −.029 |
| `b_recall` | 아래끝 ≥ −.02 | 약 .015 | ≥ −.005 | −.020 |
| `c_recall@ko` (목표) | +.03 · 아래끝 > 0 | 약 .030 | ≥ +.03 | +.117 |

- 즉 K3 는 c 이득을 **4분의 1** 만 지켜도 되지만, d 와 en b 는 **K 수준까지 거의 다** 되돌려야 한다. 이 판의 성패는 d · en b 에 걸려 있다.

| KLUE removed + 평서문 | .01 | .09 | .25 | .26 | .39 | .43 |

- **KLUE removed 는 겹침이 높다**(평서문에 질문 낱말이 남는다). 한국어 낮은 구간은 위키 같은 글 다른 문장이 메워야 한다. 구간이 모자라면 가장 덜 찬 구간에서 채우고 요약에 모자람(`short_bins_before_spill`)을 적는다.
- **기계로 거르는 것은 셋뿐이다.** ① 같은 대상 — 꼴이 보장한다(같은 지문 · 같은 위키 글 · 같은 VitaminC 쪽 = 같은 `group`). ② KLUE 는 **답 글(`answer`)이 근거에 남으면 뺀다** — 남으면 a 다. ③ 근거와 주장이 같은 문장이면 뺀다(위키 · VitaminC). 위키는 고침으로 이어진 같은 문장과 겹침 .7 이상(같은 문장의 다른 판)도 같은 문장으로 본다(리뷰 10-14). 그 밖(수치가 다른가 · 주장 사실이 근거에 없는가)은 **판정에 맡긴다.** 낱말 규칙으로 「근거에 없는 사실」을 가르면 꼴이 좁아져 새 지름길이 된다 — c 층 때 겹침이 .01~.07 로 몰린 것과 같은 함정이다.

### 4-3. 판정

- c 층(K2 설계 4-2)과 같다 : `label_batches.py make --mode train` · v6 기준 · 100쌍 묶음 · 함정 10% · 판정자 둘 · 갈림은 셋째.
- **정함 규칙** : 두 판이 다 d 일 때만 넣는다(셋째가 갈림을 d 로 정한 것 포함). c · a · b · cd 는 버린다. **c 로 정해진 줄을 c 층에 더하지 않는다** — train-g4-c 는 얼려 있다.
- 판정자는 근거 · 주장만 본다. 꼴 · 겹침 구간 · d 짝 표시는 `map/` 에만 둔다.
- **일치 문턱** : 첫 두 판 일치 **.90 아래면 멈춘다**(c 층 .994 · 평가 .970). d 는 c 보다 경계가 넓어 일치가 낮을 공산이 크다. .90~.95 면 진행하되 꼴별 일치를 결과에 적는다.
- **판정 뒤 d 칸 셈 함정** : `layer_g4c.build` 와 같은 `_drop_boundary`(cd → 버림)를 쓴다 — c 층 때 `resolve` 가 cd 에서 멈춘 함정(sets-g4 10-2).

### 4-4. 금지 · 겹침 검사

- 금지 = c 층 `make_guard` 그대로(G4Forbid 학습 몫 · `blind-g4.forbid.json` · `blind-g3.forbid.json` · g4 평가 후보 · 옛 평가 문단 색인 · scrub) **+ 얼린 `sets/g4/{blind-g4,dev-cmp-g4}.jsonl`** + **train-g4-c 의 쌍 열쇠**(같은 쌍이 c 와 d 로 두 번 나오지 않게 — 문단이 같은 것은 괜찮다).
- VitaminC 는 같은 쪽(`vitc:<쪽>` 묶음)이 평가 셋에 있으면 G4Forbid 가 묶음째 막는다. KLUE 는 dev split → 평가 · train split → 학습, 위키는 `wiki-all-eval` → 평가 · `wiki-all-train` → 학습으로 먼저 가른다.
- 조립 뒤 `assemble_g4.py check --train` 에 train-g4-d 를 더해 **blind-g4 · blind-g3 · dev-cmp-g4 · dev-cal-g3 와 묶음 · 글 · 쌍 열쇠 · 출처 id 0** 을 본다. 하나라도 있으면 멈춘다.

### 4-5. 조립 · 비율 · 얼림

- `layer_g4d.py build` — d 로 정한 줄만 · 원천 × 꼴 목표 · 묶음당 2 · `recheck` · scrub → `build/g4/train-g4-d/cands.jsonl` → `sets/g4/train-g4-d.jsonl` · `FROZEN-train-g4-d.sha256`.
- **train-g4-c · train-g3-ko 는 바이트 그대로**다. K3 와 K2 의 차는 `--train` 하나(train-g4-d)로 갈린다.

| 한 바퀴 우리 층 (replay 뺌) | K | K2 | **K3** |
| --- | --- | --- | --- |
| 쌍 | 7,045 | 8,345 | **약 9,095** |
| 새 층 셋의 d (공개 원천) | 397 | 397 | **약 1,147** |

- 가중 어림 : K2 가중에서 칸 수를 거꾸로 셈(a 약 2,220 · b 1,770 · c 2,740 · d 950) → d 에 750 을 더해 다시 역수 평균 1 로 맞춘 값.
