**길 1(한국어 NLI 분류기)은 2026-10-09 blind 332쌍을 통과했고, 같은 날 `mem` 에 꽂았다 — 상시로 켠다(사용자 2026-10-09).**
메인 PC 에 판정 서버(`nli-studio-v2`, 127.0.0.1:8092)를 늘 띄워 두고 `~/.aimemory/llm.toml` 의 `nli_url` 을 켰다. `mem` 의 판정 사다리는 이제 「규칙 → NLI → SemIf → 보류」다.
쓰면서 피드백을 받아 보완한다. 반복 끝 코드리뷰 반영은 커밋 0d9c982 로 끝났다.
**25쌍 라벨 검토 끝(2026-10-10, `../Research/2026-10-10-25쌍라벨검토.md`)** — 실물 13쌍 중 9쌍이 낡은 기억이라 모델보다 기억 품질 문제가 크다.
다음 판 순서(사용자 2026-10-10) : AIMemoryTool 기억 점검·정리 기능 → 게임 저장소 기억 정리 → **새 판정 셋으로 재측정**(blind v2 재사용 금지). JudgeModel 코드는 급한 수정 없음.
