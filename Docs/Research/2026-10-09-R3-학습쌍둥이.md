# R3 — 학습 쌍둥이 (train-sg 의 영어·섞인 판)

길 1 보강 반복 바퀴 3 의 학습 자료. 바퀴 2 에서 모델이 가장 약했던 곳은 **한·영 섞인 쌍(mix)** 이다. dev mix 정확도는 0.705였고, flip mix 의 반대는 14개 중 7개만 맞혔다. 그래서 학습 쌍 train-sg 일부를 영어(en)와 섞인(mix) 판으로 옮겨 학습에 더한다.

## 결론

- **쌍둥이 672쌍을 만들었다.** en 336 · mix 336 (근거만 영어 168 · 주장만 영어 168).
- 검사 실패 0 · 버림 0. 숫자 표기만 바뀐 허용 6건. 무작위 20쌍을 다시 읽어 **20/20 통과**했다.
- dev-r1(329쌍)과 src_ids 겹침 **0**. blind 는 열지 않았다.
- SHA-256 `2c0ac7d6e4711005988ca4f52e388236c2ee0fe3aba63f9999e701d5fc7b80d0`. 본PC와 미니PC 값이 같다.

## 왜 쌍둥이인가

- train-sg 는 거의 한국어뿐이다. 섞인 쌍을 학습에서 본 적이 없으니 dev mix 에서 무너진다.
- 같은 쌍을 언어만 바꿔 넣으면 라벨은 그대로 두고 **언어 차이만** 배우게 할 수 있다.
- R0 의 dev·blind 쌍둥이(40% · 씨앗 2)와 같은 방식이다. 씨앗만 3으로 바꿨다.

## 번역 규칙

Opus 서브에이전트가 직접 옮겼다. 40쌍씩 17묶음으로 나눠 작업했다.

- 뜻 · 숫자 · 라벨을 지킨다. 코드 이름 · 경로 · 원래 영단어는 그대로 둔다. 한글은 0자로 만든다.
- mix 는 한쪽만 옮기고, 다른 쪽은 원문을 한 글자도 바꾸지 않는다.
- **숫자는 모두 남긴다.** 「1차」는 pass 1, 「3판」은 round 3, 「1등」은 #1 처럼 옮긴다. 숫자를 낱말(two, first)로 바꾸면 숫자 검사에 걸리니 쓰지 않는다.
- 한국어 파일 이름은 뜻을 영어로 옮긴다 (예: 컨셉 문서 → 00-Concept.md). 게임 고유명사는 소리대로 적는다 (Chapssali).
- 문장이 어색한 flip 주장은 뒤집힌 뜻이 살도록 옮겨 contradict 라벨을 지킨다.
- 같은 근거·주장이 여러 쌍에 나오면 같은 번역을 다시 쓴다.
