## 왜 쓰나 · 결론 요약

이 가설은 **klue b 를 놓친 판정이 d 로 갔나 a 로 갔나**로 가려진다. 학습은 하지 않았고, 이미 있는 예측 파일만 셌다.

  K3 도 같다. 32표를 잃었고 **30표가 d, 2표가 a** 였다.
- **klue-mrc 는 전부 d 로 갔다**(d 10→25표, a 5→5표 그대로). klue-answered 는 d 가 주력이고(1→12표) a 도 조금 늘었다(21→24표).

- **klue 밖 b 는 움직이지 않았다.** 그 외 245쌍의 b 재현은 K .802 · K3 .802 · K4 .803 이다.
- **경계가 흐린 쌍이 섞여 있다(R7).** klue-mrc b 19쌍 가운데 18쌍은 처음 후보를 만들 때 **d 후보**(`hint: d`)였다. 판정자가 b 로 고친 쌍이다.

### 3-1. klue-mrc b 의 생김새

- 19쌍 중 18쌍이 `hint: d`(후보를 만들 때 d 로 만든 쌍), 1쌍이 `hint: a` 다. 판정자 둘(셋)이 b 로 정했다.

## 4. 이게 다음 판(K5) 층 설계에 뜻하는 것

판단은 사용자 몫이다. 자료와 선택지만 적는다.

**자료**

- 깨짐은 「klue b 가 줄어서」보다 **「klue d 가 커지며 같은 꼴 b 를 끌고 갔다」**에 가깝다. 잃은 표의 90% 가 d 다.
- klue-mrc 는 b 와 d 의 겉 꼴이 같고, 가르는 단서는 「반대 서술」 하나다. 그 경계에 사람 판정도 갈린 쌍이 섞여 있다(19쌍 중 표가 갈린 2쌍, 경계 중간 이상 5쌍).
- 표본이 작다. klue-mrc b 19쌍에서 쌍 하나는 b 재현 .053 이다. K4 의 −.158 은 쌍 셋 만큼이다.

**선택지**

| 선택지 | 무엇을 하나 | 이 진단이 주는 근거 |
| --- | --- | --- |
| (가) klue-mrc **b·d 짝** 층 | 같은 근거로 「반대 서술 + 없는 이름」(b)과 「없는 이름만」(d)을 짝으로 넣어, 가르는 단서를 직접 가르친다 | 오판이 d 로 가고, b·d 겉 꼴이 같다 |
| (나) klue d 층 줄이기 · b 비율 맞추기 | K4 에서 커진 klue d 몫을 b 와 같은 비율로 묶는다 | d 재현이 .395→.686 으로 오르는 동안 b 가 같이 밀렸다 |
| (다) dev 의 klue b 경계 쌍 다시 판정 | 3-2절 표의 일곱 쌍(특히 표가 갈린 2쌍)을 다시 판정하고 b@ko 자를 다시 잰다 | 의심 쌍이 새로 틀린 쌍과 겹친다(-016303 · -019452 · -007888) |
| (라) b@ko 지킴을 원천별로 보기 | klue b 39쌍을 따로 보고, 지킴은 「그 외」 b 로 본다 | 그 외 245쌍 b 는 .802 → .803 으로 안 움직였다 |

- 「한 자리만 다른 문장」(a 쪽) 축은 이번 깨짐의 원인이 아니다. 다만 mit-cs · archive b 가 .5 언저리라 따로 남는 일이다.
