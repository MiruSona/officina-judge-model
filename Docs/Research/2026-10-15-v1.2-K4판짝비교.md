**지킴 깨짐 → 접는다 · 대체 판 없음.** 설계 5-4 표대로 12단계(prereg · blind-g4 · 관문 · ONNX)로 넘어가지 않았다. 8092 는 v1.1.0 을 그대로 둔다. 다음 길은 사용자가 정한다(8절).

- **목표 `c_recall@ko`** : .7563 → **.8773**, 차 +.121 [+.0929, +.152]. 통과. 반폭 .030 < .04 라 판별 불가도 아니다.
- **지킴 아홉 중 여덟 통과, 하나 깨짐.** 깨진 것은 `b_recall@ko`(284쌍) −.019 [**−.0394**, +.0000] 하나다. 문턱 −.03 을 아래끝이 .009 넘었다.

- **경보 여덟(옛 여섯 + 새 둘)이 모두 조용하다.** K3 를 무너뜨린 「원천 한 칸 지름길」(R1)과 「d 쏠림」(R6)은 잡혔다. vitaminc c 정답을 d 로 보는 몫이 K3 의 .95 에서 .28 로 내려왔다.
- **깨진 자리는 좁다.** klue-mrc b 19쌍(.842 → .684)과 klue-answered b 20쌍(.78 → .64), 합 39쌍이 b@ko 하락의 거의 전부다. K3 도 같은 자리에서 같은 크기로 깨졌다(4절).

## 4. 왜 b@ko 가 깨졌나

**한 줄 : 깨짐은 klue 두 원천 b 39쌍에서 오고, 이 자리는 K3 에서도 똑같이 깨졌다.**

- **셈이 맞는다.** klue-mrc b 19쌍 × −.158 ≈ −3.0쌍, klue-answered b 20쌍 × −.14 ≈ −2.8쌍. 합 약 −5.8쌍 ÷ 284 ≈ **−.020** 으로, b@ko 차 −.019 를 거의 다 설명한다.
- **나머지 ko 원천 b 는 그대로다** : kobest −.019 · mem −.005 · archive +.008 · kowiki +.021 · mit-cs +.007. 서로 지워져 합은 0 근처다.
- **K3 와 같은 자리다.** K3 의 b@ko 도 −.022 [−.042, −.003] 로 같은 두 원천에서 깨졌다(klue-mrc b .653 · klue-answered b .640). K3 → K4 ko b 차는 +.003. 층을 바꿨는데도 이 자리는 안 움직였다.
- **흔들림이 크다.** 다섯 판 b@ko sd .0225 로 K(.0114)의 두 배다. 39쌍짜리 칸에서는 한 쌍이 .025 다. 구간 아래끝이 −.0394 로 문턱을 .009 넘은 것은 이 흔들림 몫이 크다.
- **층에서 klue b 가 얇다.** train-g4-bal 의 klue-mrc b 는 32줄(목표 37)이다. klue-answered b 는 층에 칸이 없다(K 처방 몫만). c · d 층이 커진 만큼 klue b 를 붙잡을 줄이 상대적으로 줄었다고 본다 — **어림이다, 재지 않았다.**
- 확인 못 한 것 : klue b 오판이 a 로 갔는지 d 로 갔는지(칸 비율 표)는 이번에 뽑지 않았다.
