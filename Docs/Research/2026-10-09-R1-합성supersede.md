# R1 — 합성 supersede 쌍 만들기 (2026-10-09)

길 1 보강 소단계 5 의 재료. 모델이 「옛 결정을 새 결정이 덮는」 반대를 「같은 주제 = 지지」로 보던 약점(`2026-10-09-N8N10-ONNX와측정.md` 6절)을 메우려고, 실물 기억에서 출발한 합성 쌍을 만들었다.

## 결론 먼저

- **1,320쌍**을 만들었다. 학습용 `train-synth.jsonl` 1,189 · 바퀴 분석용 `dev-synth.jsonl` 131 (기억 덩이 10%, 학습 안 씀).
- 갈래는 반대(B) 609+62 · 지지(A) 383+43 · 무관(C) 197+26. 지난 덧학습 셋의 supersede 44쌍보다 반대가 약 15배다.
- 다른 Opus 가 **라벨을 모른 채** support-v3 로 다시 판정해 **97.3%(942/968)** 가 맞았다. 안 맞은 26쌍은 뺐다.
- 부정어만으로 뒤집은 반대는 많아야 **6.3%**(주장에만 부정어가 새로 든 것). 상한 20% 안이다.
- 겹침 검사 여섯 가지가 모두 0 이다 (기억 train∩dev · 기억 vs 새 dev/blind · 글 train∩dev · 글 vs 새 dev · 중복 쌍 · 중복 id).
- 파일은 git 밖 `~/.judgemodel/synth/2026-10-09/` 와 미니PC `~/judgetool/mem/synth-r1/` 에 있다. SHA 는 둘이 같다.

## 만든 법

웹조사 길 3(LLM 합성 반대 + 거르기, 스튜디오 쪽 문서(비공개) 「2026-10-08-판정모델웹조사-논문.md」 3절)을 따랐다. 요점 셋 : 씨앗은 실물 문장 · 규칙 층이 잡는 꼴(부정어·숫자)은 줄이고 뜻으로 엇갈리는 반대를 늘림 · 다른 심판으로 거르기.

1. **씨앗** — 지난 덧학습 풀(미니PC `train.jsonl`+`dev.jsonl`, 1,330쌍)의 `src_ids` 598개 가운데 decision·caution 493개. 비밀 꼴(키·토큰·IP 모양)이 든 6개를 빼 **487개**. 새 dev/blind 셋의 기억 295개와는 처음부터 겹치지 않았다.
2. **근거(evidence)** — 기억 요약과 본문 첫 줄을 번갈아 썼다. 기억 하나에 근거 하나다.
3. **작성** — Opus 13판(판마다 37~38 기억). 기억마다 B 하나 + A 또는 C 하나(A 2 : C 1).
   - B 는 꼴 다섯을 골고루 섞었다 : 값만 바뀜 · 하기로 한 것을 안 하기로 · 방식 교체 · 순서 뒤집기 · 범위를 좁히거나 넓혀 무효화.
   - 지시에 「근거 낱말을 베끼지 말 것 · 부정어만으로 뒤집기 20% 이하 · mem 요약 문체」를 넣었다. 2건은 근거가 미완 문장이라 작성자가 건너뛰었다.
4. **검수** — Opus 12판. 쌍을 섞고 `q0000` 꼴 id 만 줬다. 판정 기준은 mem 저장소(비공개) 코드 `internal/llm/judge.go` 의 support-v3 원문 + 「옛 결정을 덮으면 반대」 한 줄이다.
5. **쌍둥이** — 맞은 942쌍에서 갈래마다 40% 를 골라 Opus 4판이 영어로 옮겼다. 그 절반은 en(둘 다 영어), 절반은 mix(주장만 영어 95 · 근거만 영어 94)다. id 는 `<원id>-en`·`-mix`, `src_ids` 는 원본과 같다.
6. **나누기** — 기억 단위로 섞어(seed 20261009) 10% 를 dev-synth 로 뺐다. 쌍둥이는 원본과 같은 쪽에 간다.

모든 줄의 `kind` 는 새 값 `synth-supersede` 다. `data_prep.normalize`·`train_nli.py` 는 kind 를 검사하지 않아 그대로 읽힌다(1,320줄 모두 라벨이 붙는 것 확인). B 의 뒤집기 꼴은 덤 칸 `form` 에 적었다.

## 검수 결과

| 작성 → 검수 | 쌍 |
| --- | --- |
| 일치 | 942 (97.3%) |
| 지지 → 무관 | 19 |
| 반대 → 지지 | 4 |
| 반대 → 무관 · 지지 → 반대 · 무관 → 반대 | 각 1 |

- 뺀 26쌍의 대부분은 **작성자의 A 가 너무 멀리 간 것**이다. 근거가 다루지 않는 세부만 말해 검수자가 무관으로 봤다.
- **1회차 검수는 버렸다.** 쌍 id 끝에 라벨 글자(`-a`·`-b`·`-c`)가 붙은 채 넘어가, 검수자가 라벨을 알 수 있었다(일치 99.5%). 불투명 id 로 다시 돌린 2회차 값만 쓴다.
- 한계 : 작성자와 검수자가 **같은 모델(Opus)** 이다. 같은 쪽으로 틀리는 쌍은 거르기에서 안 걸린다. 사람 검수는 아직 없다.
