## 1. 결론 먼저

**커뮤니티 글 · 댓글 그 자체는 한 곳도 못 쓴다.** 조사한 커뮤니티 열한 곳이 모두 「게시물 저작권은 글쓴이에게 있다」는 약관이고, 남(우리)에게 이용을 허락하는 CC 같은 표기가 없다. 여기에 자동 수집 금지 조항(네이버 · 디스콰이엇)이나 AI 학습 거부 신호(GeekNews `ai-train=no` · 커리어리 · 에펨코리아 robots)가 겹친 곳이 많다.
**쓸 수 있는 것은 「개발자가 쓴 한국어 문서 중 저장소 라이선스가 걸린 것의 고침 이력」뿐이다.** 그중 새로 찾은 것은 MIT 라이선스 한국어 CS · 기술면접 정리 저장소다.

## 2. 곳별

### 2-1. GeekNews (news.hada.io) — 먼저 보기로 한 곳

- **약관** [원문 `news.hada.io/terms`] : 게시물 저작권이 누구에게 있는지 적은 조항이 없다. 이용 허락 · CC 표기도 없다. 운영자 권한은 「제목, 노출 상태, 분류, 공유 여부를 조정」 · 삭제 정도다. 금지 행위에 「서비스에 과도한 부하를 주는 자동화 접근, 크롤링, 스크립트 실행 행위」가 있다. → 저작권은 저작권법대로 글쓴이에게 있고, 우리에게 넘어온 이용권이 없다.
- **robots.txt** [원문] : 첫 줄이 `Content-Signal: ai-train=no, search=yes, ai-input=yes`. ClaudeBot · GPTBot · CCBot · Google-Extended 등 학습 봇은 `Disallow: /`, 검색 · 사용자 요청 봇(Claude-User · ChatGPT-User)은 허용. **사이트가 「AI 학습에는 쓰지 말라」고 글로 밝혔다.** 이번 표본 열기는 `ai-input`(사람이 시켜서 읽기) 범위로 보고 했다.
- **RSS** [원문] : `news.hada.io/rss/news` (Atom). 공개 API 는 robots 가 `/api/` 를 막고 있다.
- **글 꼴** : 본문 대부분이 바깥 기사를 요약한 글이다(GN⁺ 요약). 댓글 중 「Hacker News 의견들」 · 「Lobste.rs 의견들」은 **바깥 사이트 댓글을 옮겨 요약한 운영자 댓글**이라 원 글쓴이 저작권이 또 걸린다. 표본 댓글 70개 중 13개가 이 꼴 [표본].
- **양** : 글 번호가 35,270 언저리 [원문 첫 화면]. 표본 20글(댓글 많은 순으로 고름)에 댓글 70 → 평균은 이보다 훨씬 낮다. 첫 쪽 글 대부분이 댓글 0~1 [원문]. 전체 댓글 수만~10만 [어림].
- **표본** [표본, 글 20 · 사람 댓글 57] : 값 · 때 · 수 · 낱말 하나가 어긋나는 b **0**. 의견 반대 1~2 (「as 의 동작을 바꿔버리는 시도」 ↔ 「동작을 바꾼다기보단 … 최적화」). 나머지는 감상 · 질문 · 덧붙임 · 농담. 「정정합니다」 꼴 댓글은 못 봤다.
- **함정** : AI 생성 본문(요약 글 · 「slop」 논쟁) · 짧은 감탄 댓글 · 영어 섞임. 글쓴이 닉네임 노출.

### 2-2. OKKY

- **약관** [원문 `okky.kr/legal/terms`] : 「게시물에 대한 저작권을 포함한 지적재산권은 당연히 권리자가 계속하여 보유합니다.」 OKKY 는 「서비스 내 노출, 서비스 홍보 … 연구 … 외부 사이트에서의 검색, 수집 및 링크 허용을 위해서만 제한적으로 행사」하는 이용권을 받는다. **남에게 다시 이용을 허락할 권리가 없다.** 자동화 금지는 「게시물을 업로드하거나 … 수정 · 변조 · 삭제」하는 쪽만 적혀 있고, 읽어 가기 금지 조항은 없다.
- **robots.txt** [원문] : 일반 봇과 ClaudeBot · GPTBot 묶음 모두 `/api/` · `/changes`(**글 수정 이력 화면**) · 사용자 활동 쪽만 막고 글은 연다. 수정 이력 화면이 있다는 점은 b 원천으로 아깝지만 robots 가 막는다.
- **양** : 글 번호 약 156만(모든 게시판 공통 번호) [원문]. Q&A 몫은 못 셌다.
- **표본** [표본, Q&A 기술 질문 20 · 답변 약 50] : 깨끗한 b 1 — 질문 「kill -15 로 주고 spring 에도 주는 설정」 ↔ 답 「spring boot 기본 프레임워크 기능을 이용 중이라면 우아한 종료를 기본적으로 구현」. 의견 반대 4 — 「화면에 종속되는 건 없습니다」 · 「자격증 유무가 전혀 중요하지 않아요」 · 「포화가 아니라 필요가 없어진 상태」 · 「시스템을 추가하는 것은 낭비 ↔ 당연히 외부 연계 서버를 이용」. 「맞는 것 같습니다」 꼴 a 도 몇 개 있다.
- **b 꼴** : 질문 속 잘못 안 사실 ↔ 답변 정정이 가장 깨끗하다. 채택 답 ↔ 비채택 답 반대는 대부분 의견이라 v6 로는 d 나 판정 보류로 샌다.
- **함정** : 답변이 여러 문장이 붙어 와 문장 쪼개기 필요 · 반말 · 줄임말(「재현 안되쪄」) · 홍보 질문 · 닉네임.

### 2-3. GitHub — 저장소 라이선스가 이슈 글에도 미치나

- **약관 D.5** [원문] : 저장소를 공개하면 다른 사용자에게 「GitHub 서비스를 통해」 쓰고 · 보이고 · 복제할 권리를 준다. 서비스 밖 재이용 · 학습 허락은 아니다.
- **약관 D.6** [원문] : 「Whenever you add Content to a repository containing notice of a license, you license that Content under the same terms」 (inbound=outbound). **커밋으로 저장소에 들어간 글은 저장소 라이선스를 따른다.** 이슈 · 토론 · PR 리뷰 댓글은 저장소 파일이 아니라서 D.6 에 드는지 약관이 말하지 않는다 → **회색, 쓰지 않는다** [원문 + 추론].
- **허용 사용 정책** [원문] : 공개 · 비개인 정보는 연구 목적이면 쓸 수 있되 「발표물이 오픈 액세스일 때만」. API 로 모으는 것은 스크래핑으로 치지 않는다. 우리 모델 공개는 연구 발표가 아니라 이 조항에 기대지 않는다.
- **결론** : 이슈 · 리뷰 댓글은 못 쓰고, **고침이 반영된 커밋(파일 글)은 저장소 라이선스대로 쓴다.** 그래서 1번 원천이 나온다.

- **양 어림** : 표본 비율(PR 20개에 b 4, 줄 쌍 약 45개 중 9%)을 큰 MIT 저장소 5개의 커밋 3,000에 얹으면 b **100~250**. 같은 꼴 MIT 저장소를 더 찾으면(GitHub 검색 「기술 면접」 · 「CS 스터디」 · 「면접 질문」 + MIT 로 겹침 포함 41개 [원문 API]) **최대 400쯤** [어림].
- **공수** : clone → `mine_archive.py revision` → 거르기 → 교사 라벨. 저장소 목록 고르기 포함 0.5~1일.
- **함정** : ① MIT 는 「저작권 고지 · 허락 문구를 함께 실을 것」이 조건 — 데이터 카드에 저장소마다 고지문을 싣는다. ② 표 · 코드 · 그림 줄 섞임 — `mine_archive` 거르기가 이미 막는다. ③ 같은 PR 이 문단을 통째로 바꾸면 한 줄 짝이 안 나온다. ④ 스터디 저장소의 PR 리뷰 댓글(표본 35개)은 거의 칭찬 · 인사라 라이선스가 풀려도 b 가 없다 [표본].

### 2-6. 그 밖 — 짧게

- **커리어리** [원문 robots] : ClaudeBot · GPTBot · CCBot · Google-Extended 등 19개 봇 `Disallow: /`. 약관 주소는 스크립트 화면이라 본문을 못 읽었다. 학습 거부가 분명해 열지 않았다.
- **velog** [원문 `velog.io/policy/terms` 5조] : 「게시물 등에 대한 저작권을 포함한 일체에 관한 권리는 별도의 의사표시가 없는 한 각 회원에게 귀속」 · 회사도 그 밖의 방법으로 쓰려면 회원 동의를 받는다. 글쓴이가 CC 를 단 글은 쓸 수 있지만 그런 글을 골라낼 표지가 없다. 공개 GraphQL API 가 있다 [기억].
- **인프런** : 이용약관 주소가 200 을 돌려주지만 본문이 스크립트라 못 읽었다 [원문 시도]. robots 는 일반 봇에 커뮤니티를 연다 [원문]. **약관 확인 전엔 못 씀**.
- **디스콰이엇** [원문 relate.kr 약관] : 제12조 ① 7 「회사의 사전 허락 없이 자동화된 수단(매크로 · 스크래퍼 등)으로 … 수집하는 등」 금지 · 제23조 「회원이 작성한 게시물의 저작권은 해당 회원에게 귀속」.
- **요즘IT** : 편집부 · 외부 필진 기사. robots 는 `/magazine/` 을 열고 `Crawl-delay: 5` [원문]. 바닥글 「© 2013 Wishket Corp.」. 반박 꼴이 아니라 b 원천이 아니다.
