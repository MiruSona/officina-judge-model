# v1.2 반대(b) 진단 — 어디로 새나 · 무엇으로 채우나 (소단계 54 · 2026-10-11)

v1.1.0(`g1-B2-s3`) 의 b 재현 .758 을 v1.2 에서 .80 이상으로 올리려고, 새는 꼴과 자료 원천을 셌다.
읽기만 했고 새 학습은 안 돌렸다. **blind-g1 · ood-g1 의 예측 출력은 열지 않았다**(셋 구성 summary 의 칸 · 도메인 수만 봤다).

## 결론

1. **릴리스 b 는 사실상 VitaminC b 다.** blind-g1 의 b 66쌍 중 **50쌍(76%)이 vitaminc** 이고 mem 3 · archive 1 이다.
   그래서 mem · git 의 덮은 결정 쌍(한국어)을 아무리 캐도 릴리스 b 자는 거의 안 움직인다. 그 캐기는 「실사용 b」 몫이다.
2. **b 는 d 보다 a 로 더 많이 샌다.** dev-cmp b 140 중 새는 38쌍이 a 22 · d 14 · c 2 다(B2 s3).
   a 로 새는 쌍은 거의 다 **「거의 같은 문장인데 한 자리만 다름」** 이다 — 비교 한정어(less than · more than) · 수 · 서수 · 낱말 하나 바꿈.
3. **라벨러도 그 자리에서 갈린다.** VitaminC 의 REFUTES(구조상 b) 를 Opus 판정이 b 로 둔 것은 52%(178/344)뿐이고 a 23% · d 22% 다.
   라벨 기준 v5 에 「비교 한정어 · 서수」 자리 규칙이 없다.
4. **합성(ㄴ)을 넣으면 b 가 c · d · a 로 고루 샌다.** 학습에 안 든 Ⅱ 의 b 244쌍(×씨앗 5)에서 b 재현이 .693 → .537. 더 샌 몫은 c +102 · d +60 · a +29 다.
   「b 가 d 로 쏠린다」는 반만 맞다. 한정어 b 는 a 로, KLUE b 는 d 로 더 샜다.
5. **수는 넉넉하다.** dev-cmp b 300 이상 + 학습 b 층은 채울 수 있다. VitaminC 남은 REFUTES 후보만 40,616(그중 heldout 8,368)이다.
   한국어 b 는 문서 한 줄 고침 약 1,640쌍(어림 b 12~20%) · 덮은 기억 쌍 128(새 것 74) 에서 200~400 을 기대한다.
6. **권고 : ① dev(그리고 다음 blind)의 b 구성을 먼저 정하고 b 300 이상으로 키운다 → ② v5 에 한정어 · 서수 규칙을 더한다 → ③ 학습에 「VitaminC 대조쌍(a · b 짝)」 + 「한국어 고침 쌍 b」 층을 d 를 안 늘리고 더한다.**
   손실 가중(b 배수)은 B1b 에서 이미 안 먹혔다. 합성은 조건을 다 채울 때만 다시 쓴다.

### 3-2. 합성(ㄴ)은 왜 b 를 깼나

| 근거 | 값 |
| --- | --- |
| 씨앗 원천 | 250 중 Ⅱ 246 · en 198 |
| 합성 셋을 외움 | syn 정확도 .966~.974 |
| 출처 판별기 | .729 (합성을 알아본다) |
| 닮음 비율 (자 ③) | 1.63~2.25배 (미달 · 참고) |
| 학습에 안 든 Ⅱ b 에서 (B2 → B3) | 한정어 b 재현 .64 → .45 (a 121 → 153) · KLUE b .70 → .48 (d 26 → 50) |

- 합성 b 는 Opus 가 근거를 다시 써서 **대놓고 어긋나게** 만든 글이다. 실물 b 는 한 자리만 살짝 다르다. 모델이 「대놓고 어긋남」만 b 로 배우고, 실물의 작은 어긋남은 a · c · d 로 보냈다고 본다.
- 같은 주장에 근거 넷(a · b · c · d)을 붙인 꼴이라, 주장만 보고 b 를 짐작하던 단서도 약해졌다(c 재현 +5.9%p 가 같이 오름).

**다시 쓸 조건(다 채울 때만)** : b 만 만든다 · 씨앗은 한국어 실물(mem · 문서) · **한 자리만 바꾼 최소 고침** 꼴(㉠ ㉡) · 같은 씨앗의 최소 고침 a 짝을 같이 넣는다 · 출처 판별기 .65 아래 · 학습 b 의 25% 이하 · 학습에 안 든 Ⅱ b 혼동표로 먼저 본다.

## 4. b 가 d 로 쏠리는 현상

| 판 | 무엇을 더함 | b 가 간 곳 | 근거 |
| --- | --- | --- | --- |
| B1 · B1b (Ⅱ) | 공개 4,813 (d 1,479 · b 244) | **못 잼** — dev 쌍별 예측이 지워짐 | 학습 dev 의 b 재현은 .758 → .756 그대로 |
| B3 (합성) | syn 908 (b 248) | 학습에 안 든 Ⅱ b : c +102 · d +60 · a +29 (×5 씨앗) | `B3/train-pred` vs `B2/train-pred` |

**가설 셋**

1. **b 비중이 묽어짐 (B1).** 학습 쌍 b 비율이 17% → 13% 로 줄고 d 는 크게 늘었다. b×2.0 으로도 안 돌아온 것은 가중이 문제가 아니라 Ⅱ 의 b 가 「쉬운 VitaminC b」 위주라 dev 의 mem · 한정어 b 를 못 가르쳤기 때문으로 본다(쌍별 근거 없음 · 확인 못 함).
2. **꼴이 안 맞는 b (B3).** 위 3-2.
3. **라벨 경계 흔들림.** 같은 꼴(한정어 · 낱말 하나 바꿈)이 학습 라벨에서 a · b · d 로 갈리면, d 를 늘릴수록 그 쪽으로 끌린다. ㉣(번호만 다름) · ㉥(KLUE 답 바꿈)은 v5 로도 b · d 가 갈린다.

**막는 법**

| 방법 | 기대 | 근거 |
| --- | --- | --- |
| 손실 가중 b↑ | **낮음** | B1b b×2.0 이 b 를 −2.4 → −3.4%p 로 더 내림 |
| 대조쌍 (같은 주장 · a 판 근거와 b 판 근거를 짝으로) | **높음** | 새는 몫 61~69% 가 「거의 같은 문장」 꼴. VitaminC 가 원래 이 구조다 |
| v5 손질 (한정어 · 서수 · 낱말 하나 · 번호만 다름) | 중간 | 라벨러 b 남김률이 한정어 74% vs 없음 40% |
| d 를 늘리지 않음 (b 층은 a · b 만) | 지킴 | Ⅱ · 합성 둘 다 d · c 가 같이 늘 때 b 가 깨짐 |

| F. 합성 다시 | 조건부 | 큼 | ㄴ 전례 −6.9%p |

**권고 : A → C → (B + D 를 한 조건으로) 순서.**

- A 가 먼저다. 지금 dev-cmp b 는 mem 50 · vitaminc 66 인데 blind-g1 b 는 vitaminc 50 · mem 3 이다. 무엇을 「b 80%」 라고 볼지(릴리스 셋 구성)를 먼저 정해야 B · D 의 효과를 잴 수 있다. blind-g1 은 v1.1 때 한 번 썼으니 v1.2 릴리스용 새 blind 가 필요한지도 이때 정한다.
- C 를 B · D 판정 전에 한다. 새로 판정할 쌍이 v5 의 빈 자리(한정어 · 낱말 하나)에 몰려 있기 때문이다.
- B 와 D 는 둘 다 「거의 같은 문장 · 한 자리 다름」 b 를 채운다. 한 조건(B4 = B2 + b 층)으로 묶어 짝 비교 한 번에 본다. d 는 더하지 않는다.
