## 7. 함정

- **`pgrep -f <이름>` 을 ssh 로 돌리면 원격 셸 자기 자신의 명령 줄도 걸린다.** 끝난 판을 「아직 도는 중」 으로 8분 기다렸다. 끝은 로그의 마지막 줄이나 산출물로 본다(`미니PC.local.md` 의 `grep -v pgrep` 와 같은 뿌리).
- **`python -I` 는 `PYTHONIOENCODING` 을 무시한다.** 한글 표를 찍는 스크립트는 안에서 `sys.stdout.reconfigure(encoding="utf-8")` 를 한다. Windows 기본은 cp949 라 `—` 에서 죽는다.
- Git Bash 에서 `--set name=~/…` 의 `~` 는 안 풀린다. `C:/Users/…` 꼴로 적었다.
