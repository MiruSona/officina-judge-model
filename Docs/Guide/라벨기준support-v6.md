## 1. 네 칸

| 칸 | 글자 | 정의 | 한 줄 시험 |
| --- | --- | --- | --- |
| 0 | a 지지 | 근거가 주장의 **어느 한 부분이라도** 맞다고 받친다 | 주장 속 말 중 근거가 「맞다」고 해 주는 것이 하나라도 있나 |
| 1 | b 반대 | 근거와 주장의 어느 부분이 **둘 다 참일 수 없다** | 함께 참일 수 없는 말이 하나라도 있나 |
| 2 | c 무관 | **다른 대상**을 말한다 | 같은 사물 · 사건 · 기능 · 규칙 · 수치 자리를 가리키지 않는다 |
| 3 | d 비슷한 계열 | **같은 대상**을 말하지만 받치지도 뒤집지도 않는다 | 같은 대상에 대한 글인데 서로 다른 사실을 말한다 |

- 칸 번호(a 0 · b 1 · c 2 · d 3)는 v4 · v5 와 같다. 옛 번호 · 옛 쌍 라벨은 그대로 쓴다.

### 1-1. 「같은 대상」의 뜻

같은 대상 = 두 글이 **같은 것 하나를 가리킨다.**

| 같은 대상이다 | 같은 대상이 아니다 |
| --- | --- |
| 같은 사물 (같은 사람 · 같은 앨범 · 같은 파일) | 같은 큰 분야 (같은 툴 · 저장소 · 프로젝트 · 게임) |
| 같은 사건 (같은 출시 · 같은 사고 · 같은 회의) | 같은 위키 문서 · 같은 설계 문서 안의 다른 절 |
| 같은 기능 · 같은 규칙 | 같은 사람이 쓴 글 · 같은 날 쓴 글 |
| 같은 수치 자리 (같은 지표의 값) | 낱말이 많이 겹치는 것 |
| 같은 결정 자리 (무엇을 쓸지 · 몇으로 할지) | 같은 주제 낱말(「성능」 · 「캐시」)만 같은 것 |

- **오른쪽은 근거가 아니다.** 문서 · 분야가 같아도 가리키는 것이 다르면 c 다.

### 1-2. 우선순위

**b > a > d > c.** 위에서부터 먼저 걸리는 칸을 붙인다.

- 일부를 받쳐도 어긋나는 말이 하나 있으면 **b**.
- 어긋남이 없고 받치는 말이 하나라도 있으면 **a**.
- 같은 대상인데 둘 다 없으면 **d**. 다른 대상이면 **c**.

## 2. 2단 지침 — 예/아니오 셋

질문 셋을 **차례로** 묻고, 답(예/아니오 + 짧은 까닭)을 먼저 적은 뒤 칸을 고른다.

| 차례 | 질문 | 「예」면 | 「아니오」면 |
| --- | --- | --- | --- |
| Q1 | **같은 대상인가?** (1-1 표) | Q2 로 | **c** |
| Q2 | **함께 참일 수 없는 말이 있나?** | **b** | Q3 으로 |
| Q3 | **근거가 맞다고 해 주는 말이 주장에 하나라도 있나?** | **a** | **d** (아래 한 번 더) |

- **d 를 붙이기 전 한 번 더** : 숨은 부분 지지가 없나 본다.
  - 같은 사실을 다른 말로 썼나 (「값을 올렸다」 ↔ 「값이 커졌다」).
  - 수를 다른 단위 · 다른 꼴로 썼나 (「90초」 ↔ 「1분 30초」 · 「절반」 ↔ 「50%」).
  - 주장의 이름 · 날짜 · 장소 하나라도 근거가 맞다고 해 주나.
  - 하나라도 있으면 a 다. 없으면 d.
- Q1 에서 정말 못 고르면 `cd` 를 붙일 수 있다. **학습 셋에서만** 쓴다(dev · blind · gold 에는 넣지 않는다).
- 질문이 Q2 · Q3 차례인 까닭 : 우선순위가 b > a 라서, 받치는 말이 있어도 어긋나는 말이 먼저다.

## 3. 자주 갈리는 자리 규칙

| 자리 | 규칙 | 보기 (지어냄) |
| --- | --- | --- |
| 같은 수치 자리 · 다른 값 | 같은 때 · 같은 조건이면 **b**, 때 · 조건이 다르면 **d** | 「3월 사용자 120만」 ↔ 「3월 사용자 90만」 → b |
| | | 「2023년 매출 120억」 ↔ 「2024년 매출 150억」 → d |
| | | 「기본 설정에서 지연 40ms」 ↔ 「캐시를 끄면 지연 90ms」 → d (조건이 다름) |
| ① 비교 한정어 · 때 비교 (넘음 · 아래 · 까지 · 앞 · 뒤 · more than · less than · after) | 근거가 **같은 때 · 같은 조건**의 값을 주고, 주장의 범위가 그 값을 **빼면 b**, **넣으면 a**. 근거에 그 자리 값이 없거나 때 · 조건이 다르면 **d** | 「그 도시 인구는 4만 7천이다」 ↔ 「그 도시 인구는 5만이 넘는다」 → b (4만 7천은 5만 넘음 범위 밖) |
| | | 「그 가게는 2014년 4월에 문을 열었다」 ↔ 「그 가게는 2014년 뒤에 문을 열었다」 → b |
| | | 「그 도시 인구는 4만 7천이다」 ↔ 「그 도시 인구는 4만이 넘는다」 → a (범위 안) |
| | | 「2019년 그 도시 인구는 4만 7천」 ↔ 「2023년 그 도시 인구는 5만이 넘는다」 → d (때가 다름) |
| ② 서수 · 순위 | **같은 순위표 · 같은 때**에서 서수가 다르거나, 서수와 「앞선 곳 몇」이 어긋나면 **b**. 같으면 **a**. 순위표나 때가 다르면 **d** | 「그 팀은 올해 리그에서 4위다」 ↔ 「올해 리그에서 그 팀보다 앞선 팀이 넷이 넘는다」 → b |
| | | 「그 앨범은 2020년 판매 3위」 ↔ 「그 앨범은 2023년 판매 5위」 → d (때가 다름) |
| ③ 낱말 하나 바꾼 거의 같은 문장 | 바뀐 자리가 **값 하나만 갖는 자리**(누가 냈나 · 처음 · 켬/끔 · 몇 개 · 태어난 곳)면 **b**. **둘 다 참일 수 있는 자리**(참여한 곳 · 쓴 툴 중 하나 · 나온 작품 중 하나)면 **d**. 겹치는 낱말이 많다는 것은 a 의 근거가 아니다 | 「그 게임은 A 사가 냈다」 ↔ 「그 게임은 B 사가 냈다」 → b |
| | | 「자동 저장은 기본으로 끈다」 ↔ 「자동 저장은 기본으로 켠다」 → b |
| | | 「그 영화 제작에 A 사가 참여했다」 ↔ 「그 영화 제작에 B 사가 참여했다」 → d (둘 다 참여했을 수 있음) |
| ④ 근거 표지 번호만 다름 | 같은 결정 · 같은 사실의 **근거 자리**에서 번호(리뷰 R3 · 실측 T5 · 소단계 12)만 다르면 **b** (같은 자리 다른 값). 글이 근거를 **여럿** 든다고 드러나면 **d**. 근거 자리 밖의 말을 받치는지는 1-2 우선순위대로 본다 | 「캐시를 끄기로 했다. 근거 : 리뷰 R4」 ↔ 「캐시를 끄기로 했다. 근거 : 리뷰 R3」 → b |
| | | 「이 결정의 근거로 리뷰 R3 · R4 를 든다」 ↔ 「이 결정의 근거로 리뷰 R5 도 든다」 → d (근거가 여럿인 자리) |
| 다음 단계 | 앞 단계 결과를 다시 말하면 **a**, 새 일만 말하면 **d** | 「캐시를 붙였다」 ↔ 「캐시 뒤 지연이 줄었다」 → d |
| | | 「캐시를 붙였다」 ↔ 「캐시를 붙인 뒤 지연이 줄었다」 → a (붙였다는 말을 받침) |
| | | 「1차 시험 통과」 ↔ 「2차 시험 날짜를 정했다」 → d |
| 답 없는 질문을 바꾼 문장 | 지문이 그 답을 말하지 않고 반박도 안 하면 **d**. 지문이 다른 답을 말하면 **b** | 지문 「그 다리는 1950년에 지었다」 ↔ 「그 다리는 강철로 지었다」 → d |
| | | 지문 「그 다리는 돌로 지었다」 ↔ 「그 다리는 강철로 지었다」 → b |
| 같은 문서 다른 절 | 같은 대상이 아니면 **c**. 문서가 같다는 것은 근거가 아니다 | 설계 문서의 「동기」(로그 압축) ↔ 「되돌리는 법」(설정 파일 복원) → c |
| | | 같은 문서 「명세 : 시간 제한 30초」 ↔ 「하위 호환 : 시간 제한을 안 적은 옛 설정은 그대로 돈다」 → d (같은 시간 제한 자리) |
| 덮은 결정 (Superseded) | 옛 결정을 뒤집으면 **b**, 덧붙이거나 좁히면 **a**, 같은 자리의 다른 면만 말하면 **d** | 「저장 형식은 JSON」 ↔ 「저장 형식을 YAML 로 바꾼다」 → b |
| | | 「저장 형식은 JSON」 ↔ 「JSON 에 판 번호 칸을 더한다」 → a |
| | | 「저장 형식은 JSON」 ↔ 「저장 파일은 날마다 백업한다」 → d |
| 같은 사람 · 다른 일 | 사람이 같아도 말하는 사건 · 속성이 다르면 같은 대상인지 먼저 본다. 같은 사람의 다른 속성은 **d**, 그 사람과 상관없는 다른 사건이면 **c** | 「그 배우는 1909년생이다」 ↔ 「그 배우는 영화 쉰 편에 나왔다」 → d |
| | | 「그 배우의 고향은 항구 도시다」 ↔ 「그 항구 도시의 인구는 30만이다」 → c (대상이 도시로 바뀜) |
| 일부만 빠진 근거 | 근거가 주장의 한 부분을 받치고 다른 부분만 빠졌으면 **a** (d 아님) | 「그 앨범은 1990년에 나왔다」 ↔ 「그 앨범은 1990년에 A 사에서 나왔다」 → a |
| | | 「그 앨범은 A 사에서 나왔다」 ↔ 「그 앨범의 표지는 흑백이다」 → d |

- 표에 없는 자리는 2절의 Q1 → Q2 → Q3 차례로만 가린다. 「느낌상 비슷하다」는 근거가 아니다.

**우선 순위** — 한 쌍이 규칙 둘에 걸리면 아래를 따른다.

- **때가 다른 두 결정 글이면 「덮은 결정」이 ③ · ④ 보다 먼저다.** 뒤 글이 옛 결정을 뒤집으면 b, 덧붙이면 a, 다른 면만 말하면 d.
- **② 는 「같은 수치 자리」의 순위판이다.** 순위 · 서수 · 「앞선 곳 몇」이면 ② 를 쓴다.
- **① 은 주장에 비교 한정어가 있을 때, 「같은 수치 자리」는 두 글 다 값을 그대로 적을 때 쓴다.** 때 · 조건이 다르면 둘 다 d 다.
- **근거가 바뀐 자리의 값을 아예 말하지 않으면 「답 없는 질문」이 ③ 보다 먼저다** → d. ③ 은 근거가 그 자리 값을 직접 적을 때만 쓴다.
- **③ · ④ 와 「일부만 빠진 근거」가 겹치면 b.** 나머지 말을 받쳐도 값 하나 자리가 어긋나면 b > a 다.

### 3-1. 자주 틀리는 자리

라벨러가 같은 꼴을 b · a · d 로 갈라 붙인 자리다(한정어 없는 반대 문장이 b 40% · a 30% · d 25%).

| 경계 | 틀리는 쪽 | 바른 쪽 |
| --- | --- | --- |
| **b ↔ a** : 거의 같은 문장에 낱말 하나만 다름 | 겹치는 낱말이 많아서 「받친다」고 a | 바뀐 한 낱말이 값 하나 자리면 **b**. 나머지가 같다는 것은 b 를 막지 않는다(1-2 b > a) |
| **b ↔ d** : 바뀐 자리가 값 하나인지 여럿인지 | 「누가 냈나」 · 「켬/끔」 · 「몇 위」까지 「둘 다 있을 수 있다」고 d | 둘이 동시에 참일 수 없는 자리면 **b**. 「참여한 곳 · 쓴 툴 중 하나」처럼 여럿이 함께 참일 수 있을 때만 **d** |
| **b ↔ d** : 근거에 그 자리 값이 없거나 때가 다름 | 주장이 틀려 보인다고 짐작으로 b | 근거가 같은 때 · 같은 조건의 값을 **글로 적을 때만** b. 값이 없거나 때 · 조건이 다르면 **d** |

### 3-2. 보충 2026-10-14 — 대상을 이름 없이 가리키는 근거

근거가 대상을 이름 대신 대명사나 일반명사(It · the film · the band · 그 · 이 작품)로 가리킬 때의 규칙이다. 판정자마다 c 와 d 로 갈렸던 자리라 더했다. 기준 판 이름은 v6 그대로다.

- **다른 대상이라는 단서가 없으면 같은 대상으로 본다.** 그다음은 평소대로 가린다 — 받치면 **a**, 함께 참일 수 없으면 **b**, 근거에 없는 사실이면 **d**.
- **c 는 다른 대상이라는 단서가 글에 있을 때만** 붙인다. 단서는 이름 · 시기 · 장소가 주장과 어긋나는 것이다.

| 근거 | 주장 | 칸 |
| --- | --- | --- |
| 「이 작품은 개봉 첫 주에 관객 30만을 모았다」 | 「그 영화의 감독은 신인이다」 | d (같은 대상 · 근거에 없는 사실) |
| "It received a 92% approval rating from critics." | "The film was released in 2015." | d (같은 대상 · 근거에 없는 사실) |

### 3-3. 덧붙임 2026-10-26 — 때만 다른 쌍 · 같은 단위 다른 사실

이 판에서는 기준 판 이름을 v6 그대로 둔다. 다음 라벨 판이 v7 로 올리며 본문 표에 넣는다.

- **값은 같고 적은 때(기록 · 결정 날짜)만 다른 쌍은 d 다.** 같은 결정 · 같은 값을 날짜만 바꿔 다시 적은 것이다. 받치는 말이 있어도 a 가 아니라 d 로 붙인다(Q3 의 예외 — 합칠 자리라서). 「덮은 결정」 규칙보다 먼저다.
  - 사건의 때 자체가 바뀌면 이 줄이 아니다. 「2014년에 문을 열었다」 ↔ 「2016년에 문을 열었다」 는 같은 수치 자리 다른 값이라 **b** 다.
- **같은 단위의 다른 사실은 b 가 아니다.** 같은 일의 다른 순간 · 다른 칸을 같은 단위 숫자로 적었으면 값이 달라도 함께 참일 수 있다. **d 인지 c 인지는 다음 라벨 판에서 정한다.**

| 근거 | 주장 | 칸 |
| --- | --- | --- |
| 「캐시 크기는 64MB 로 정했다 (3월 2일)」 | 「캐시 크기는 64MB 로 정했다 (3월 9일)」 | d (값 같음 · 때만 다름) |
| 「시험 시작 10분 뒤 첫 오류가 났다」 | 「시험 시작 25분 뒤 서버를 껐다」 | d 또는 c — 다음 라벨 판에서 정함 (b 아님) |

## 4. 쌍 파일에 적는 값 (v4 · v5 와 같음)

| `want` 값 | 뜻 | 쓰는 곳 |
| --- | --- | --- |
| `support` · `a` | 지지 | train · dev · blind |
| `contradict` · `b` | 반대 | train · dev · blind |
| `unrelated` · `c` | 무관 | train · dev · blind |
| `related` · `d` | 비슷한 계열 | train · dev · blind |
| `cd` | c 와 d 중 하나 (못 고름) | **train 만.** `split_pairs.py` 가 dev 에 들어가면 멈춘다 |

- v6 로 판정한 줄은 `label_guide: "support-v6"` 를 적어 v5 쌍과 섞이지 않게 한다.

## 5. v4 → v5 에서 달라진 점 (기록)

| 자리 | v4 | v5 | 까닭 |
| --- | --- | --- | --- |
| c / d 시험 | 「한 문서의 **같은 절**에 넣을 글인가」 | 「**같은 대상**(사물 · 사건 · 기능 · 규칙 · 수치 · 결정 자리)을 가리키나」 | 「같은 절」은 문서를 쓰는 사람마다 다르다. 대상은 글만 보고 가릴 수 있다 |
| 정의의 말 | 합치기 큐 말(「merge 큐 문턱」 · 같은 scope) | 쓰는 쪽과 무관한 말 | 공개 범용 판정 모델이라 기억 저장소 말에 묶이지 않게 |
| 「같은 분야」 | 「같은 scope 는 기준이 아니다」 | 「같은 툴 · 저장소 · 프로젝트 · 위키 문서 · 게임은 기준이 아니다」로 넓힘 | 공개 원천(위키 · 제안서 · 이슈)도 같은 규칙으로 |
| 묻는 법 | 표 보고 바로 칸 하나 | **Q1 → Q2 → Q3 예/아니오를 먼저 적고** 칸 고름 | LLM 라벨러가 바로 d 에서 흔들린다. 예/아니오로 쪼개면 빠르고 덜 흔들린다 |
| d 전 확인 | 없음 | 숨은 부분 지지(다른 말 · 다른 단위) 한 번 더 | 같은 사건 짝의 다수가 부분 함의라는 보고 |
| 자리 규칙 | 다섯 줄 | 일곱 자리 · 자리마다 보기 둘 이상 | 수치 · 질문 바꾸기 · 덮은 결정처럼 공개 원천에서 자주 나오는 자리 |
| 영어 쌍 | 언급 없음 | 같은 글을 그대로 쓴다(번역하지 않음) | 영어 원천을 번역 없이 씀 |
| `cd` | 학습에서만 | 같음. dev · blind · **gold** 에 안 넣음을 적음 | 정답셋이 새로 생김 |
